# Benchmarks

Generated by `ram bench report` from the JSON files in `bench/results/`. Do not edit by hand.

Method: every trial runs a **relief** arm (macOS's memory-pressure signal at critical) and a **control** arm (identical timing, no signal) in a seeded random order with a cooldown between arms. Numbers are phys_footprint (Activity Monitor's Memory column) summed per app; apps busy during the 2 s baseline and apps that started or quit mid-window are not counted. Welch's t-test compares the arms.
